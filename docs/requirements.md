# 要件定義書 (Requirements Specification)

## 1. プロジェクト概要

### 1.1 背景と目的

日々の出来事や内省（気づき・失敗談・学び）をストックし、自己成長につなげるアプリ「Stockr」の有料化に伴い、同等のコアバリューを備えた代替アプリケーション「Stockly（ストックリー）」を自作する。

### 1.2 コアコンセプト

> **「日々の出来事・気づき・失敗談を手軽にストックし、AIの壁打ちコメントや過去の再発見（リマインド）を通じて内省・自己改善を促すリフレクションアプリ」**

単なるメモ帳・日記アプリではなく、以下の体験を提供することを目的とする：

1. **ストック（蓄積）**: 気軽に短いテキストや画像をストック。テンプレートや問いかけで投稿ハードルを下げる。
2. **AIフィードバック**: 投稿内容に対するAIからの共感・アドバイス・気づきを即時提供。
3. **再発見（リフレクション）**: 過去のストック（数ヶ月前、1年前等）をリマインドし、過去の失敗や教訓を再認知。
4. **目標・ビジョンとの接続**: 日常のストックを自身のビジョンや目標と紐付け、目的意識を持った蓄積を促進。
5. **ゲーミフィケーション**: スコア、ストック数、再発見回数、連続記録日数（ストリーク）による継続性の向上。

| 画面名                     | 主な役割・概要                                                           |
| -------------------------- | ------------------------------------------------------------------------ |
| **ホーム画面**             | 日常の起点。目標確認、チュートリアル、今日のストック、AIコメント表示     |

## 3. 機能要件

### 3.1 ストック（記録）機能

- **テキスト記録**:
  - 自由記述の複数行テキスト入力
  - 入力補助プロンプト（「最近の出来事をふりかえってみよう」等の日替わり/ランダム問いかけ）
- **テンプレート機能**:
  - 振り返りフレームワーク（例: YWT「やったこと/わかったこと/次にやること」、KPT「Keep/Problem/Try」、事実と教訓など）をワンタップで本文に挿入可能
- **テーマ・目標との紐付け**:
  - 投稿時にあらかじめ設定した「目標」や「テーマ（カテゴリ）」を選択してタグ付け
- **画像添付**:
  - デバイスからの画像アップロード・プレビュー・保存
- **CRUD操作**:
  - ストックの新規作成、編集、削除、詳細閲覧

### 3.2 AI連携機能 (Stockly-AI)

- **自動フィードバックコメント**:
  - 投稿保存時にAIがストック内容を解析し、共感コメント、改善のための問いかけ、アドバイスを自動生成
  - ホーム画面およびストックカード下部にアコーディオン形式または専用ブロックで表示
- **入力時AIアシスト**:
  - 入力中にアイデア出し、文章のブラッシュアップ、内省を深める質問生成の支援

### 3.3 再発見（リフレクション・リマインド）機能

- **過去ストックのピックアップ**:
  - 過去の同時期（例: 1週間前、1ヶ月前、1年前）やランダムな過去のストックを一覧トップにハイライト表示
  - 「忘れていた失敗や気づき」をリマインドし、同じ過ちの再発防止や成長実感を与える
- **再発見アクション**:
  - ピックアップされたストックを読了/再確認したことによる「再発見カウント」の加算

### 3.4 ゲーミフィケーション & 統計（レポート）機能

- **主要メトリクスのトラッキング**:
  - **スコア (Points)**: 投稿、AIとの対話、再発見の実行などに応じた加点
  - **ストック数 (Stock Count)**: 累計記録件数
  - **再発見数 (Rediscovery Count)**: 過去の記録を再確認した回数
  - **連続記録 (Streak)**: 日々の連続投稿日数
- **レポート・ダッシュボード**:
  - 週間・月間の記録推移やカテゴリ別分布の可視化

### 3.5 検索 & フィルタリング機能

- **キーワード検索**:
  - ストック本文のインクリメンタル検索（全文検索）
- **フィルター**:
  - 「すべて」「テーマ別」「目標別」での絞り込み表示
- **ソート**:
  - 投稿日時（新しい順／古い順）

### 3.6 ビジョン & 目標管理機能

- **ビジョン管理**:
  - 人生のありたい姿、長期的な指針の登録・閲覧・更新
- **目標管理**:
  - 短期・中期の達成目標の登録・ステータス管理
- **オンボーディング・ガイド**:
  - アプリの活用方法を段階的に進めるステップガイド（例: `0/8` ステップ進捗表示）

### 3.7 通知 & アカウント管理

- **リマインダー通知**:
  - 指定した時間（夜の振り返りタイム等）に記録を促すプッシュ通知
- **ユーザー設定**:
  - プロフィール設定、テーマカラー切り替え、データエクスポート（JSON/CSV）

---

## 4. 非機能要件

- **レスポンシブ / モバイルファースト**:
  - スマートフォンでの片手操作・快適な入力を最優先としたUI/UX
- **オフライン対応 / 高速な入力体験**:
  - 思いついた瞬間に待たされずすぐ書ける起動速度とレスポンス
- **セキュリティ・プライバシー**:
  - 個人の内省・失敗談などのセンシティブな情報を扱うため、データ暗号化および適切なアクセス制御
