# UI仕様書 (UI Specification)

各画面のレイアウトおよびUIコンポーネントの仕様です。

---

## 1. 共通レイアウト & ナビゲーション

### 1.1 グローバルボトムナビゲーションバー
画面下部に固定されるナビゲーション。
- **ホームタブ（左）**:
  - アイコン: 家アイコン (`Home`)
  - ラベル: `ホーム`
  - 遷移先: ホーム画面
- **ストック追加ボタン（中央・FABスタイル）**:
  - アイコン: プラス記号 (`+`)
  - 形状: ターコイズブルーの円形フローティングボタン（バーから少し飛び出るアクセントデザイン）
  - 挙動: モーダルまたはフルスクリーンでストック入力画面を起動
- **ストックタブ（右）**:
  - アイコン: レイヤー／ストックアイコン (`Layers`)
  - ラベル: `ストック`
  - 遷移先: ストック一覧・検索画面

## 2. 画面別UI仕様

### 2.1 ホーム画面

```
+---------------------------------------------------+
|  Stockly                            [🔔]  [👤]    |  <-- ヘッダー
+---------------------------------------------------+
|  [🚩 ビジョン]                                   > |
|  ビジョンを設定しましょう                           |
+---------------------------------------------------+
|  [🎯 目標]                                      > |
|  目標を設定しましょう                             |
+---------------------------------------------------+
|  [📖 はじめ方ガイド]                             > |
|  ストックに何を書く？                              |
|  [=======-----------------------] 0/8   [...]     |
+---------------------------------------------------+
|  [📅 今日のストック]                               |
|  +---------------------------------------------+  |
|  | セゾンアメックスゴールド 年一度でも利用...   |  |
|  |                                             |  |
|  | 13:19                             [✨] [...] |  |
|  +---------------------------------------------+  |
|  | Stockly-AIからのコメント >                  |  |
|  +---------------------------------------------+  |
+---------------------------------------------------+
```

- **ヘッダー**:
  - 背景に薄いエメラルドグリーン／ターコイズのグラデーションヘッダー
  - ブランドフォントの「Stockly」ロゴ
  - 右上に通知ベルアイコン（未読オレンジドット）、プロフィールアイコン（未読オレンジドット）
- **プロモーション／目標設定カード群**:
  - 角丸カード（白背景、淡い枠線）
  - 各カードにアイコン、タイトル、説明文、右矢印 `>`
  - はじめ方ガイドにはプログレスバーと進捗テキスト（`0/8`）およびサブメニュー `...`
- **「今日のストック」セクション**:
  - セクションヘッダー: カレンダーアイコン付き見出し
  - 本日のストックカード:
    - 本文（複数行テキスト）
    - 投稿時刻（例: `13:19`）
    - 右下アクション: AIアイコン（表情＋キラキラ）、サブメニュー `...`
    - カードフッター: 「Stockly-AIからのコメント >」（タップでAIコメントがアコーディオン展開）

### 2.2 ストック入力・作成画面

```
+---------------------------------------------------+
|  [✕]                                [ストックする] |  <-- ヘッダー
+---------------------------------------------------+
|  [+ テーマ・目標を設定]                            |  <-- タグ/カテゴリチップ
|                                                   |
|  最近の出来事をふりかえってみよう                   |  <-- プレースホルダー
|                                                   |
|  [📋+ テンプレートを使う]                         |  <-- テンプレート挿入
|                                                   |
|                                                   |
|                                                   |
+---------------------------------------------------+
|  [🖼️]  [✨]                                       |  <-- 入力補助ツールバー
+---------------------------------------------------+
|                [ ソフトウェアキーボード ]           |
+---------------------------------------------------+
```

- **ヘッダー**:
  - 左: キャンセル用バツアイコン（`✕`）
  - 右: プライマリアクション「ストックする」（文字が未入力の時は無効化/グレー表示）
- **入力領域**:
  - 上部に「`+ テーマ・目標を設定`」のアウトラインピル型ボタン
  - プレースホルダー: 「最近の出来事をふりかえってみよう」等の内省を促すテキスト
  - 「`テンプレートを使う`」リンクボタン: タップで振り返り用テンプレート選択モーダルを表示
  - 自由編集可能なテキストエリア
- **入力ツールバー**:
  - キーボードの直上に配置
  - 左側: 画像添付アイコン（カメラ／ギャラリー起動）
  - 左側（画像アイコン隣）: AI支援アイコン（プロンプト提案、文章の整理）

### 2.3 ストック一覧・検索・レポート画面

```
+---------------------------------------------------+
|  [🔍 キーワード検索                  ]      [⇅]   |  <-- 検索バー & ソート
+---------------------------------------------------+
|  (すべて)  (...)                                  |  <-- フィルターチップ
+---------------------------------------------------+
|  [📊 レポート                                  > ] |
|    [📈] 770 pt     [🗂️] 44 件    [⚡] 1 件  [🔥] 1 回 |
|    スコア          ストック      再発見     連続記録 |
+---------------------------------------------------+
|  [⚡ 再発見                                    > ] |
|  (2024/09/29のストック)                            |
|  金沢含む三泊四日旅行のための薬をちぎって...         |
+---------------------------------------------------+
|                    2026/05/04                     |  <-- 日付セパレーター
|  +---------------------------------------------+  |
|  | 2026-04-09 ラブサイケデリコのライブの...      |  |
|  |                                             |  |
|  | 2026/05/04                        [✨] [...] |  |
|  +---------------------------------------------+  |
|                    2026/01/15                     |
|  +---------------------------------------------+  |
|  | 沖縄のアルモントホテルの冷蔵庫にお茶と...     |  |
|  |                                             |  |
|  | 2026/01/15                        [✨] [...] |  |
|  +---------------------------------------------+  |
+---------------------------------------------------+
```

- **検索 & フィルターエリア**:
  - 角丸のキーワード検索入力フィールド
  - 右側にソートアイコン（上下矢印 `⇅`）
  - その下にスクロール可能なフィルターチップ列（「すべて（選択中）」、「`...`」）
- **レポートサマリーカード**:
  - 右上に「レポート >」リンク
  - 4カラムの統計メトリクス:
    1. **スコア**: `770 pt`（上昇グラフアイコン）
    2. **ストック**: `44 件`（レイヤーアイコン）
    3. **再発見**: `1 件`（稲妻アイコン）
    4. **連続記録**: `1 回`（炎アイコン）
- **再発見（リフレクション）ハイライトカード**:
  - 稲妻アイコンと「再発見 >」ヘッダー
  - 過去のストック日時（例: `(2024/09/29のストック)`）
  - 過去ストック本文のプレビュー（タップで全体表示・詳細へ）
- **ストックタイムライン**:
  - 中央揃えの日付ラベル（例: `2026/05/04`, `2026/01/15`, `2025/11/24`, `2025/11/21`, `2025/11/08`）
  - 各ストックカード:
    - 本文表示
    - 投稿日付または時刻表示
    - AIコメントリアクションアイコン、詳細メニューアイコン（`...`）
