# Stockly (日々のストック・内省 PWA アプリ)

日々の出来事、反省、気づきをストックし、AI パートナーの知的な問いかけや過去の再発見（リマインド）を通じて内省・自己改善を促すリフレクション PWA アプリです。

- **本番 URL**: **[https://stockly.ohchans.com](https://stockly.ohchans.com)** (PWA インストール対応)
- **認証保護**: Cloudflare Zero Trust Access（ワンタイム PIN 認証）対応

---

## 📱 アプリの使い方ガイド

### 1. ホーム画面への追加 (PWA インストール)

Stockly は Progressive Web App (PWA) として設計されており、ネイティブアプリ同様に全画面で快適に動作します。

- **iPhone / iPad (Safari)**:
  1. `https://stockly.ohchans.com` を Safari で開く
  2. 画面下部の中央にある **共有ボタン**（四角から矢印が出ているアイコン）をタップ
  3. **「ホーム画面に追加」** を選択
- **Android (Chrome)**:
  1. Chrome でアプリを開く
  2. 右上のメニュー（︙）から **「アプリをインストール」** または **「ホーム画面に追加」** をタップ
- **PC (Mac / Windows - Chrome, Edge)**:
  1. アドレスバー右端に表示される **インストールアイコン** をクリック

### 2. 主要画面と機能

```
┌────────────────────────────────────────────────────────┐
│  Stockly            🔥 3日連続   Lv.2 (60pt)    ⚙️      │
├────────────────────────────────────────────────────────┤
│  💡 今日の再発見                                         │
│  「1ヶ月前の気づき：朝の散歩は思考整理に効果的...」          │
├────────────────────────────────────────────────────────┤
│  🔍 キーワード検索...                   [#学び] [#習慣]  │
├────────────────────────────────────────────────────────┤
│  【タイムライン】                                       │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 2026/10/04 10:30                       [#自己改善] │  │
│  │ 初めて新しい技術スタックで本番リリースを完了した。       │  │
│  │ ──────────────────────────────────────────────── │  │
│  │ ✨ AIパートナーからの問いかけ:                       │  │
│  │ 「今回の挑戦で、一番学びになったプロセスは何でしたか？」│  │
│  └──────────────────────────────────────────────────┘  │
├────────────────────────────────────────────────────────┤
│   [🏠 タイムライン]     [➕ 投稿]     [🎯 目標]   [📊 統計]│
└────────────────────────────────────────────────────────┘
```

#### ✍️ 1. ストックの投稿（クイック入力 & テンプレート）

- 画面下部の中央にある **「＋」ボタン** をタップすると、即座に入力モーダルが開きます。
- **テンプレート活用**:
  - モーダル上部のタグ/テンプレートボタンから「事実・感情・学び」「KPT」「YWT」などのフレームワークをワンタップで本文に挿入可能。
- **タグ付け**:
  - `#自己改善` `#仕事` `#健康` などのタグを自由に追加・管理できます。
- **軽快な保存**:
  - 「ストックする」を押すと、**待たされることなく一瞬でモーダルが閉じ**、タイムラインに即時反映されます。

#### 🤖 2. AI パートナーによる知的な問いかけ

- ストック投稿後、Cloudflare Workers AI（**Meta Llama 3.3 70B**）がバックグラウンドで内容を深く解釈します。
- よくある定型文（「素晴らしい内省ですね！」等）を排除し、**文脈に即した深いオープンクエスチョン**（「その時どう感じた？」「次に活かすとしたら？」）を生成してカード内に表示します。
- 投稿直後（30秒以内）はパルスアニメーション付きで「AI パートナーが問いかけを考えています...」と表示され、生成完了次第、画面をリロードすることなく自動反映されます。

#### 💡 3. 今日の再発見 (Rediscovery)

- 過去のストックから 1 日 1 件を厳選し、タイムライン最上部にピックアップ表示します。
- 過去の反省や決意を定期的に思い返すことで、思考のループや成長の定着を促します。

#### 🔥 4. ゲーミフィケーション (ストリーク & レベル)

- **連続日数 (Streak)**:
  - 日本時間 (JST) 基準で毎日ストックを記録すると、ヘッダーの連続記録カウンター（🔥）が加算されます。
- **リフレクティブレベル**:
  - 投稿ごとにスコア（+10pt、継続ボーナス等）が加算され、レベルアップバッジが進みます。

#### 🎯 5. 目標・ビジョン管理 (Goals タブ)

- 人生のビジョンや短期・中期・長期の目標をカテゴリ別に登録可能。ストックと紐づけて内省の軸を保ちます。

#### 📊 6. レポート & 統計 (Reports タブ)

- 週間・月間の記録推移や頻出タグの分布を可視化し、自身の関心や思考の傾向を客観的に把握できます。

## 🛠 技術スタック

| レイヤー                 | 採用技術                            | 特徴・選定理由                                                   |
| :----------------------- | :---------------------------------- | :--------------------------------------------------------------- |
| **フロントエンド**       | **Svelte 5 (Runes) + Tailwind CSS** | 仮想 DOM なしの超軽量・最速起動 PWA。直感的なリアクティビティ    |
| **統合ツールチェーン**   | **Vite+ (`vp`)**                    | Rolldown・Vitest 5・Oxlint・Oxfmt による高速 Rust ツールチェーン |
| **バックエンド API**     | **Cloudflare Workers + Hono**       | エッジ分散実行、Zod + Hono RPC による完全型安全 End-to-End       |
| **データベース**         | **Cloudflare D1**                   | サーバーレス分散 SQLite データベース                             |
| **メディアストレージ**   | **Cloudflare R2**                   | APAC リージョンの高速 S3 互換オブジェクトストレージ              |
| **AI エンジン**          | **Cloudflare Workers AI**           | `@cf/meta/llama-3.3-70b-instruct-fp8-fast`（予備: `3.2-3b`）     |
| **CLI ツールチェーン**   | **`cf` (`cf@1.0.0-beta.12`)**       | Cloudflare 公式の次世代統合 CLI（Wrangler 後継）                 |
| **インフラコード (IaC)** | **Pulumi (`@pulumi/cloudflare`)**   | TypeScript による宣言的な本番インフラ自動プロビジョニング        |

### 詳細コマンドガイド

#### 1. ローカル開発サーバー起動

```bash
# フロントエンド (Svelte 5 PWA): http://localhost:5173 または同一LANから http://<ローカルIP>:5173
pnpm dev

# バックエンド (Workers API + ローカル D1): http://127.0.0.1:8787
pnpm dev:api
```

#### 2. 品質検査・テスト (Vite+)

```bash
# 静的検査 (高速型チェック + Oxlint + Oxfmt)
pnpm check

# 自動整形・自動修正
pnpm run check:fix

# Vitest 5 による高速自動テスト実行 (9ファイル・45テストが約1秒で完了)
pnpm test
```

#### 3. E2E 自動ブラウザテスト (Playwright)

Chromium 実ブラウザを用いたユーザー体験・クリティカルパスの自動検証環境です。
**ローカル起動アプリ** と **本番環境アプリ** の2種類のターゲットに対応しています。

```bash
# ローカル起動アプリへの E2E テスト (ポート 8787 / 5173 を自動起動してテスト)
pnpm run test:e2e:local
# または
pnpm run test:e2e

# 本番環境 (https://stockly.ohchans.com) への E2E テスト
# ※ 事前に 'pnpm run access:off' で Access をバイパスにするか、認証済み環境で実行します
pnpm run test:e2e:prod

# ローカル・本番の両方を一括実行
pnpm run test:e2e:all
```

#### 4. Cloudflare Access (Zero Trust) 認証 ON / OFF 切替

本番ドメイン（`https://stockly.ohchans.com`）のアクセス保護をターミナルから一撃で切り替えられます。

```bash
# 現在の保護状態を確認
pnpm run access:status

# 普段（本番保護モード）: .env (CLOUDFLARE_ACCESS_EMAIL) へのワンタイムPIN認証を有効化
pnpm run access:on

# 開発・検証時: 認証画面をスキップ（Bypassモード）して誰でも直接アクセス可能に
pnpm run access:off
```

#### 5. 次世代 Cloudflare CLI (`cf`) の利用

```bash
# cf CLI バージョン確認
pnpm cf --version

# D1 データベース一覧
pnpm cf d1 list

# Access アプリケーション一覧
pnpm cf zero-trust access applications list

# 本番へのデプロイ
pnpm deploy
```

#### 6. 過去データ移行 (CSV インポート)

過去に記録したメモ（CSVファイル）を Cloudflare D1 へ安全に一括インポートできます。

```bash
# ドライラン（投入前のデータ件数・フォーマット整合性チェック）
pnpm import:csv --dry-run

# ローカル D1 へインポート
pnpm import:csv --local

# 本番 D1 へインポート
pnpm import:csv --remote --db stockly-db-prod
```

#### 7. 本番インフラプロビジョニング (Pulumi IaC)

Cloudflare 上に D1 データベース（`stockly-db-prod`）や R2 バケット（`stockly-media-prod`）をコードから自動作成します。

```bash
# 変更内容の事前プレビュー
pnpm --filter @stockly/infra exec pulumi preview

# 本番インフラの適用
pnpm --filter @stockly/infra exec pulumi up -y
```
